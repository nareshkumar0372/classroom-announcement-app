# Classroom Announcement App

A modern and professional Classroom Announcement Application developed using Flutter and Firebase.  
This application allows teachers to create and publish announcements in real time, while students can easily view announcements through a clean and user-friendly interface.

---

# Features

## Authentication System
- User Registration using Email & Password
- Secure Login System
- Firebase Authentication Integration
- Logout Functionality

## Teacher Dashboard
- Professional Dashboard Interface
- Quick Navigation Cards
- Teacher Welcome Section
- Easy Announcement Management

## Announcement Management
- Add New Announcements
- View All Announcements
- Detailed Announcement Screen
- Real-time Firestore Updates
- Date & Posted User Information

## Professional UI Design
- Modern Material UI
- Gradient App Bars
- Card-Based Layout
- Responsive Design
- Smooth Navigation
- Attractive Color Theme
